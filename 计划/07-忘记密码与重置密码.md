# 忘记密码与重置密码

## 目标

让未登录用户可以通过邮箱申请一次性重置凭证，并使用凭证设置新的登录密码。

## API

- `POST /api/v1/auth/forgot-password`：提交邮箱，生成 30 分钟有效的重置凭证。
- `POST /api/v1/auth/reset-password`：提交凭证和新密码，更新密码并立即作废凭证。

## 安全约定

- 数据库只保存重置凭证的 SHA-256 哈希，不保存明文凭证。
- 凭证只能使用一次，过期后不可使用。
- 未注册邮箱也返回统一成功消息，避免暴露账号是否存在。
- 当前没有邮件服务，申请接口返回 `reset_token` 供本地开发页面完成闭环；接入邮件服务时由邮件投递该凭证。
