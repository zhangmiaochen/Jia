# 接口连接排障

## 目标

确保网页端不会误连其他本机服务，并支持桌面浏览器、局域网手机浏览器访问 Jia API。

## 约定

- Jia API 默认监听 `:8081`，避开开发环境中已占用的 8080 端口。
- 网页端默认根据当前访问主机拼接 `http://{host}:8081/api/v1`，也可使用 `VITE_API_URL` 覆盖。
- API 仅允许 HTTP 5173 前端来源进行跨域请求。
- 网络不可达时显示实际 API 地址，HTTP 错误显示状态码或后端错误消息。

## 启动方式（重要）

- 数据库默认路径 `data\jia.db`、存储目录 `storage` 均相对**进程工作目录**解析，必须在 `Jia_api` 目录下启动服务：
  - `.\run-server.ps1`（自动切换到脚本所在目录后 `go run ./cmd/server`）
  - 或手动：`cd Jia_api` 后 `go run ./cmd/server`
- 首次运行前先执行 `.\run-migrate.ps1`（等价 `go run ./cmd/migrate`）初始化 schema。
- 服务启动日志会打印数据文件的**绝对路径**；若在错误目录启动（如 `cmd` 内），会提示“数据库缺少 users 表”并拒绝启动，避免出现“密码正确却提示密码错误”的假象。
- 排查登录失败时，可直接调用 `POST /api/v1/auth/forgot-password` 提交邮箱：返回中出现 `reset_token` 表示账号在当前服务所连数据库中，返回空表示账号不在该库（多为服务连错数据库）。
